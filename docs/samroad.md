# SAM Road Prototype
The purpose of this prototype is to explore the SAM Road Repository for Sentinel 2 data.

## Cloning Repo
``` bash
git clone https://oauth2:{your_git_hub_pat}@github.com/kelviy/InstaRoad.git
```

## SAM Road Repository
We use this as a base for the prototype

## Data Preparation
The instructions from RNGDet++ was followed to download the datasets for "SpaceNet" and "CityScale".

The data was imported to Kaggle Datasets.

## Bash Scripts
The bash script "prepare_kaggle.bash" perform:
- data manipulations required for SAM Road
- git clones the SAM Road repository
